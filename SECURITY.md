# Security policy

## Reporting a vulnerability

Please report security issues privately through the repository host's security
advisory feature or to the maintainers' private contact listed in the repository
settings. Include affected versions and a concise reproduction when possible.
Do not post exploitable details in a public issue before maintainers have had a
chance to respond.

This package currently has no published security support window. Reported issues
will be triaged by maintainers on a best-effort basis.
