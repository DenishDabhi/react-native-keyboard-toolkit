# Contributing

Thanks for helping improve Keyboard Shepherd.

## Development

1. Use Node.js 22.11 or newer and install dependencies with `npm ci`.
2. Run the app with `npm run android` or `npm run ios` after configuring the
   React Native native toolchain for your platform.
3. Run `npm run validate` before submitting changes.
4. Include tests for behavior changes and update relevant documentation.

Keep pull requests focused, preserve existing public behavior where possible,
and describe any platform limitations. Do not include credentials, generated
build output, or device-specific files.

## Reporting issues

Include React Native and OS versions, device/emulator details, keyboard and
window settings, a minimal reproduction, and relevant logs. Do not attach
personal or confidential data.

By contributing, you agree that your contributions are provided under the
project's MIT license.
